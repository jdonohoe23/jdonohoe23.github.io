Portfolio

South Dakota Flood Recovery

GIS work focused on recovery mapping and spatial analysis related to flood impacts. The project highlights data organization, map communication, and problem-solving in a real-world event context.

Habitat Suitability and Change Detection for Moose in Isle Royale National Park

Graduate work examining habitat suitability and landscape change for moose in Isle Royale. This project combines ecological thinking, spatial analysis, and conservation-focused GIS.

Shortleaf Pine Cover Loss Using Landsat 4-5 (TM Sensor)

Remote sensing project analyzing forest cover loss over time using Landsat imagery. It shows experience with land cover change detection and environmental monitoring.

LCFPD Trail System Animal Sightings

Current field-based project using GPS waypoints to track animal sightings along Lake County forest preserve trails. This connects on-the-ground observations with conservation mapping and data management.

Lake County, IL LULC 1990 - 2005

Land use / land cover analysis comparing historical patterns across Lake County, Illinois. This project demonstrates long-term spatial change analysis and cartographic presentation.
